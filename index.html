❓ Solar FAQ

3 KW solar system kis ke liye suitable hai?

Requirement electricity consumption, sanctioned load, roof area aur system type par depend karti hai. Calculator sirf starting estimate deta hai.

On-Grid aur Hybrid me difference kya hai?

On-Grid system electricity grid ke saath operate karta hai. Hybrid system battery backup ko include kar sakta hai. Final configuration requirement ke according decide hoti hai.

Solar installation se pehle kya chahiye?

Recent electricity bill, roof information, available space aur electricity load ki information helpful hoti hai.
